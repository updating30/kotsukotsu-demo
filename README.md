# こつこつ — 習慣トラッカー（体験版）

かわいい仲間と一緒に、毎日の習慣をこつこつ記録する習慣トラッカーアプリの**体験版**です。

**体験版（ブラウザで開けます）**：https://updating30.github.io/kotsukotsu-demo/

## 体験版について

- 見本の記録（運動・勉強・健康の3テーマ、約1か月半分）が最初から入っています。統計やふりかえりの画面まで、そのまま見られます
- 記録は**保存されません**。ページを開き直すと、見本の状態に戻ります
- 体験版では、ホーム画面へのインストールと通知は使えません

## アプリでできること

- **ホーム**：テーマごとの習慣を、タップひとつで記録。カレンダー、連続記録、今日のミッション
- **統計**：週・月・年・全期間の達成率、曜日別の傾向、達成の内訳
- **ふりかえり**：期間のまとめと最長連続記録。気づきのメモと次の目標を書ける
- **マイページ**：レベル、なかま図鑑（記録でたまる「きらめき」でガチャを回して仲間を集める）、実績バッジ

## 作りの特徴

- サーバー不要。製品版はオフラインでも動き、記録はすべて端末の中だけに保存（PWA：iPhone・Android のホーム画面に追加してアプリとして使える）
- 「続けたくなる」しかけ：記録するたびにポイント、仲間集め、バッジ、ミッション、BGMと効果音
- 仲間のキャラクターは、作者の手描きをもとに作ったオリジナルです
